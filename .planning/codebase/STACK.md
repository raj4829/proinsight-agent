# Technology Stack

## Core
- **Language**: Python 3.10+
- **Framework**: Streamlit (Frontend & Application Host)

## Data & Analytics
- **Database**: DuckDB (In-process OLAP database)
- **Data Processing**: Pandas, NumPy
- **Forecasting**: Scikit-Learn (Linear Regression)
- **Visuals**: Plotly Express & Graph Objects

## AI Intelligence
- **Framework**: Agno Agent System
- **LLM**: OpenAI GPT-4o
- **Capability**: Natural Language to SQL (NL2SQL), Strategic Insight Generation

## Utilities
- **PDF Generation**: FPDF
- **Normalization**: Unicodedata
- **Environment**: Python Virtual Environment (venv)
