3. Run these 3 commands one by one:


## Step 3: Connect & Push

On your GitHub page, you will see a section "…or push an existing repository from the command line". Copy those exact commands or use these (replace `YOUR_USERNAME` with your real username):

```bash
# 1. Point to your local main branch
git branch -M main

# 2. Link your computer to GitHub
git remote add origin https://github.com/YOUR_USERNAME/proinsight-agent.git

# 3. Upload your code!
git push -u origin main
```
