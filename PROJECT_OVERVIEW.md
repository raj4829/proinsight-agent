# ProInsight Analyst: Project Overview

## 1. Project Goal
**To empower Business Analysts and Marketing Specialists** with an AI tool that automates data querying, KPI dashboarding, and executive reporting. It bridges the gap between raw CSV/Excel files and actionable strategic insights without requiring advanced SQL knowledge.

## 2. Core Architecture
The application follows a **Streamlit + DuckDB + LLM (Agno/OpenAI)** architecture.

### A. Frontend (Streamlit)
- **Framework**: `streamlit` (Python library for rapid web apps).
- **Role**: Handles UI layout, file uploads, chat input, and data visualization.
- **Key Files**: `pro_insight_analyst.py`.

### B. Data Engine (DuckDB)
- **Technology**: `duckdb` (In-process OLAP database).
- **Role**:
    - Acts as a high-performance in-memory SQL engine.
    - Directly injests Pandas DataFrames from uploaded CSV/Excel files.
    - Executes the SQL queries generated by the AI agent.
- **Why DuckDB?**: It is faster than SQLite for analytical queries (SUM, AVG, GROUP BY) and requires zero server setup.

### C. AI Brain (Agno Agent + OpenAI)
- **Library**: `agno` (Agentic framework).
- **Model**: OpenAI `gpt-4o` (or similar).
- **Pattern**: **"SQL Generator"**.
    - The Agent does *not* execute code directly.
    - Instead, it **writes SQL queries** based on the user's natural language question.
    - The app extracts this SQL and runs it safely against DuckDB.

## 3. Key Features & Workflows

### 📊 Feature 1: The Automated Dashboard
*   **How it works**:
    1. User uploads a file.
    2. The `detect_kpi_metrics()` function scans column names for keywords like "Revenue", "Cost", "Clicks", "Impressions".
*   **Frontend**: Streamlit (Python) - Interactive Web Interface
*   **Database**: DuckDB (In-Memory) - Very fast SQL engine for analytics
*   **AI Brain**: Agno Agent + OpenAI (`gpt-4o`) - Generates SQL and Strategic Insights
*   **Visualization**: Plotly - Interactive, zoomable charts
*   **Forecasting**: Scikit-Learn - Linear Regression for time-series prediction
*   **Reporting**: FPDF - Programmatic generation of branded PDF reports

## 3. Key Features
### 📂 Agency Data Hub (Multi-File)
*   Upload multiple CSV/Excel files at once (e.g., Sales, Ad Spend, Inventory).
*   Automatic date parsing and table registration.
*   **Capability**: The AI knows about *all* tables and can write `JOIN` queries across them.

### � Interactive Visualization
*   Replaced static charts with **Plotly**.
*   Auto-detects best chart type (Line for dates, Bar for categories).

*   **Predictive Analytics**: Uses historical data to train a regression model.
*   Projects trends for 30, 60, or 365 days into the future.
*   Visualizes "Actual" vs "Forecast" data on a single timeline.

### 📑 White-Label Reporting
*   **Calculated Metrics**: Extracts hard numbers (Total Revenue, ROI) directly from data.
*   **AI Strategy**: Generates "Executive Analysis" and "Recommendations".
*   **Professional PDF**: Downloads a clean, structured PDF ready for clients.
