# ProInsight Design System (MASTER)
> **Generated by UI/UX Pro Max Intelligence**
> **Product**: SaaS Business Intelligence Platform
> **Target**: Senior Executives & Strategic Consultants

---

## 🎨 Brand Identity & Style
- **Pattern**: Dashboard-Centric (Bento Grid)
- **Style**: **Enterprise Minimal**
- **Keywords**: Precision, Trust, High-Velocity, Modern.
- **Goal**: High readability for complex data with zero visual fatigue.

### Color Palette (Deep Ocean SaaS)
| Role | HEX Code | Usage |
| :--- | :--- | :--- |
| **Primary** | `#0F172A` | Navigation, Heavy Headings, Dark UI Elements |
| **Secondary** | `#0EA5E9` | CTA Buttons, Active States, Key Highlights |
| **Accent** | `#10B981` | Positive Trends, Success States, "Growth" Visuals |
| **Danger** | `#EF4444` | Negative Trends, Errors, Critical Alerts |
| **Background** | `#F8FAFC` | Main app background (Clean white-smoke) |
| **Surface** | `#FFFFFF` | Card backgrounds, Sidebar containers |
| **Border** | `#E2E8F0` | Subtle separation of elements |

### Typography
- **Primary Font**: `Inter` (Sans-serif) via Google Fonts.
- **Data Font**: `Roboto Mono` (Monospace) for metrics and digits (to ensure numbers align vertically).
- **Body Size**: `16px` (Minimum for mobile/desktop readability).
- **Line Height**: `1.6` for readability.

---

## 📐 Layout & Components
- **Metric Cards**: Use the **Bento Grid** layout. White background, 1px subtle border, 12px border-radius.
- **Charts**: Use Plotly with UUPM colors. No background grids (keep it clean).
- **Sidebar**: Fixed width (260px), dark theme to contrast with white content area.
- **Buttons**: Rounded (8px), transition speed `200ms`, `cursor-pointer` always.

---

## 🚫 Anti-Patterns (Avoid at all costs)
- **NO** emojis as primary icons (Always use SVGs/Lucide).
- **NO** "AI Purple/Pink" gradients (Looks unprofessional for BI).
- **NO** harsh drop shadows (Use `0 1px 3px 0 rgba(0, 0, 0, 0.1)` instead).
- **NO** centered text for body paragraphs (Always left-align for data readability).

---

## ✅ Pre-Delivery Checklist
- [ ] Contrast ratio is at least 4.5:1 for all text.
- [ ] Touch targets are minimum 44x44px.
- [ ] Hover states have smooth `200ms` transitions.
- [ ] Numbers are displayed in `Roboto Mono` for precision.
- [ ] App is fully responsive at 375px (Mobile).
